# Emergency-Response-Dashboard

## 📊 Project Overview

The Emergency Response Dashboard is a Power BI data analytics project designed to monitor and analyze emergency department operations and patient flow.

The dashboard provides insights into patient arrivals, waiting times, treatment duration, admissions, discharge patterns, patient satisfaction and Left Without Being Seen (LWBS) cases.

## 🎯 Project Objective

The objective of this project is to use data visualization and analytics to help identify operational patterns, monitor emergency department performance and support data-driven decision-making.

## 🛠️ Tools Used

- Power BI
- Power Query
- DAX
- Microsoft Excel

## 🧹 Data Preparation

The dataset was cleaned and transformed using Power Query.

Key data preparation activities included:

- Handling missing values
- Standardizing data types
- Creating patient ID fields
- Extracting arrival hours from timestamps
- Creating month and day-of-week fields
- Calculating waiting time
- Calculating treatment time
- Calculating length of stay
- Preparing categorical fields for analysis

## 📌 Key Performance Indicators

The dashboard tracks important emergency department KPIs including:

- Total Patient Visits
- Admission Rate
- Discharge Rate
- Average Waiting Time
- Average Treatment Time
- Average Length of Stay
- Patient Satisfaction
- LWBS Rate
- Patients Seen Within Target Time

## 📈 Dashboard Analysis

The dashboard provides analysis of:

- Patient arrival patterns
- Waiting time
- Treatment time
- Patient flow
- Admission and discharge patterns
- Patient satisfaction
- LWBS cases
- Department performance
- Peak arrival periods
- Demographic characteristics

## 🔍 Key Insights

The analysis was used to identify patterns in emergency department activity, including patient arrival trends, waiting times, treatment duration, admission patterns and patient satisfaction.

These insights can help healthcare management identify areas requiring operational improvement.

## 💡 Recommendations

Based on the analysis, healthcare management can use the dashboard to:

- Monitor patient waiting times
- Identify peak periods of patient arrivals
- Improve patient flow
- Monitor LWBS cases
- Evaluate department performance
- Improve resource allocation
- Monitor patient satisfaction
